# MyoJi

EMG tokenization: each electrode sends one 10-bit token every 20 ms instead of raw EMG.

This repository will hold `myoji`, the code for *EMG Tokenization Preserves Movement Information at a
Fraction of the Bitrate* (Raul C. Sîmpetru, Amin Olamazadeh, Devon Rohlf, Vlad Cnejevici and Alessandro
Del Vecchio, Friedrich-Alexander-Universität Erlangen-Nürnberg). The code is released with the preprint;
until then the repository contains the project page.

- Project page: <https://nsquaredlab.github.io/MyoJi/>, built from [`website/`](website/) by
  [`.github/workflows/website.yml`](.github/workflows/website.yml) on every push to `main`.
